## ✨ What to Try

### 1. The Briefing (Main Tab)
- **Pull down** to refresh (see haptic animation)
- **Scroll through** 4 sections (Markets, Local, Sports, Weather)
- **Read articles** with images and summaries
- **Scroll to bottom** for "You're done!" message

### 2. Settings Tab
- **Tap Settings** (⚙️ icon at bottom)
- **Toggle Sports OFF** → Go back to Briefing → Sports section gone!
- **Change Font Size to Large** → Text scales up everywhere
- **Hide Images** → Cards show text only (data saver mode)
- **Turn off Volume** → Header no longer shows "Vol. 1, No. 42"

### 3. Navigation
- **Switch tabs** (bottom bar: Briefing ↔ Settings)
- **See preferences persist** (settings affect briefing in real-time)
